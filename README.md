# CoupleCare - Resolve Conflicts Together

A guided relationship tool for couples who want to stop arguing and start understanding. Built with Next.js, Tailwind CSS, and Framer Motion.

## Features

- **Conflict Resolution Flow** - A guided 5-step process to work through disagreements constructively
- **Cool Down Zone** - Breathing exercises (Box, 4-7-8, Resonance) and grounding prompts for when emotions run high
- **"I Feel" Statement Builder** - Transform blame into constructive communication using the NVC formula
- **Fair Fighting Rules** - 10 evidence-based guidelines for keeping arguments productive
- **Conflict Journal** - Track disagreements and resolutions over time, spot patterns, celebrate growth
- **Appreciation Wall** - A shared space for gratitude notes to remember what's right in your relationship

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Privacy

All data is stored locally in your browser's localStorage. Nothing is sent to any server.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide Icons
