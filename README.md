# Relationship Alarm App

Relationship conflict support flow for moments of escalation:

1. **Alarm trigger**: either partner can hit the alarm.
2. **Dual notification**: both people are notified that the conversation is entering red territory.
3. **Pause + techniques**: guided cooldown with practical regulation options.
4. **Listen to both sides**: capture each partner's perspective before solving.
5. **Find and suggest solutions**: app proposes concrete next-step options.

## Run locally

```bash
npm install
npm run dev
```
